# Inspeção de Linhas de Transmissão — site offline

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (pode ser público).
2. Envie **todos os arquivos desta pasta** para a raiz do repositório (`index.html`, `app.js`, `style.css`, `sw.js` e `manifest.webmanifest`).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)` e clique em **Save**.
5. Abra o endereço publicado usando HTTPS. Na primeira visita, mantenha a internet ativa para o site armazenar os arquivos.
6. Depois da primeira carga, o site poderá ser aberto sem internet no mesmo navegador/dispositivo. Também pode ser instalado como aplicativo quando o navegador oferecer essa opção.

## Recursos
- Checklist com os 12 grupos e 94 pontos extraídos da planilha.
- Situação REG/IRREG, data de correção e observação por item.
- Identificação da LT, torre, equipe e observações gerais.
- Salvamento automático no navegador.
- Busca, filtros, indicadores, impressão/PDF e backup JSON para exportar/importar.

## Atenção
O armazenamento é local ao navegador e dispositivo. Use **Exportar backup** regularmente para não perder registros ao limpar os dados do navegador ou trocar de aparelho. O GitHub Pages hospeda os arquivos; não sincroniza automaticamente os dados preenchidos.

## Atualização: observações finais e fotos
A versão atual inclui um campo de observações finais e anexos de até 5 fotos por inspeção. As fotos são reduzidas no próprio navegador e ficam no armazenamento local junto com os dados; também entram no backup JSON e aparecem na impressão/PDF. Para evitar perda de registros, exporte backups com frequência. O armazenamento continua sendo local ao navegador/dispositivo.
